AI fundamentals

The AI landscape

Tools fall into a few families. Pick by the job, not the brand.

Chat assistants

ChatGPT for general writing, research, analysis and coding. Claude for long documents, careful writing and code. Gemini for AI inside Google's apps.

Answer engines

Perplexity searches the web and cites its sources, so it suits research where you want to check the trail.

Coding helpers

GitHub Copilot suggests code inside your editor. Best when you already write some code.

App builders

Lovable turns a plain-English description into a working app. Best when you want a product without coding.

How AI has evolved

1950s–80s

Rule-based

Hand-written if-then rules and expert systems.

1990s–2000s

Machine learning

Programs learn patterns from data instead of rules.

2010s

Deep learning

Neural networks master images, speech and translation.

2020–23

Generative AI

Chatbots write, draw and code on request.

2024 on

AI agents

Models use tools and take multi-step actions.

Now

Autonomous workflows

Agents work on longer tasks while you supervise.
